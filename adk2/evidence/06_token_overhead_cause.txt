## Reading
ADK 2.x quotes every event authored by another agent inside <<<BEGIN/END_QUOTED_AGENT_CONTENT>>> markers,
preceded by a ~400-char anti prompt-injection preamble. The first request is identical in both versions; the
overhead grows with every prior inter-agent event that is replayed as history (+1392 chars for the 2nd agent,
+2784 for the 3rd, +4176 for the 4th in this trace).
